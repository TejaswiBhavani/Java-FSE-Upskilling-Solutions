# Cognizant - Java FSE Upskilling and DeepSkilling Solutions

## Overview
This repository contains the solutions, projects, and hands-on labs (HOLs) completed as part of the Java FSE upskilling journey. It is structured into three main areas:

- **`Upskilling/`**: Foundational and advanced assignments, exercises, and learning modules.
- **`Deepskilling/`**: Deep-dive topics and weekly exercises, including JUnit testing, RESTful Web Services, Microservices, ReactJS, and more.

### Final Project
- **`FinalProject/`**: A capstone project that combines **HTML, CSS, Bootstrap, and Database** integration, showcasing all the skills and technologies learned throughout the upskilling modules.

## Technologies Covered
Throughout the modules in this repository, various technologies and concepts are explored, including but not limited to:
- Java & Advanced Java Concepts
- Spring Boot & Spring Data JPA
- RESTful Web Services & Microservices
- JUnit & Mockito for Testing
- HTML, CSS, Bootstrap, JavaScript
- ReactJS for Frontend Development
- Database Management (SQL/NoSQL)
- Git

## Getting Started
To get started with any of the projects, navigate to the specific module's directory and follow the instructions provided in its respective `README.md` file (if available) or check the source code for setup instructions.
